# RAG 基础原理（示例文档）

本文档用于验证知识入库链路。将本目录下的文档替换为真实知识库内容即可。

## 什么是 RAG

RAG（Retrieval-Augmented Generation，检索增强生成）把外部知识注入大模型的回答过程：
先从知识库中检索与问题相关的文本片段，再把片段作为上下文拼进提示词，让模型基于事实回答，
从而缓解幻觉问题，并支持私有知识的问答。

## 知识入库流程

知识入库是离线的一次性操作，分为四步：

1. 解析：用 Apache Tika 把 PDF、Word、PPT、HTML 等文件转成纯文本。
2. 切分：用 TokenTextSplitter 按 token 数把长文本切成适合向量化的短块，中文场景建议自定义句读标点。
3. 向量化：用 embedding 模型把每个文本块转成固定维度的浮点向量。
4. 存储：向量连同原文与元数据一起写入向量库。

## 查询流程

用户提问时，问题本身也会被向量化，然后与库中向量做余弦相似度计算，
取最相关的若干块拼入提示词交给对话模型生成回答。查询路径不做任何入库操作。
